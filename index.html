Как узнать Bot Token и Chat ID

Шаг 1. Создайте своего бота и получите Bot Token
  1. Откройте в Telegram официального бота @BotFather.
  2. Отправьте ему команду /newbot.
  3. Придумайте любое имя (например: Мои приглашения) и уникальный логин, заканчивающийся на bot (например: my_love_invite_bot).
  4. В ответ @BotFather пришлёт длинный код — HTTP API Token (вида 7123456789:AAH...). Скопируйте его.
Шаг 2. Узнайте свой Chat ID (куда бот пришлёт карточку)
  1. Найдите в поиске Telegram только что созданного вами бота и обязательно нажмите кнопку «Запустить» (/start) — иначе бот не сможет вам написать!
  2. Откройте в Telegram бота @userinfobot (или @getmyid_bot) и нажмите «Запустить».
  3. Он сразу пришлёт ваш цифровой Id (например: 519283746). Это и есть ваш Chat ID.
Шаг 3. Как отправить карточку девушке или парню
  1. Вставьте Bot Token и свой Chat ID в поля на этом сайте.
  2. Выберите все пункты для свидания и нажмите синюю кнопку «Отправить интерактивную карточку в Telegram».
  3. Бот мгновенно пришлёт красивую интерактивную карточку вам в личку — просто перешлите это сообщение девушке или парню в ЛС!
💡 Для запуска прямо внутри Telegram (Mini App): в @BotFather отправьте /newapp, выберите своего бота и вставьте ссылку на этот сайт в поле Web App URL.
